## The money math (keep consistent)

| Item | Value |
|---|---|
| Bought (2004) | $380,000 |
| Improvements (kitchen, deck) | $70,000 → **cost basis $450,000** |
| Refinance (2021) | $360,000 at 2.9%, 30 yrs → **$1,498/month** P&I; balance after 5 yrs ≈ **$319,476** ("about $320K") |
| Home value (2026) | $1,200,000 → equity ≈ $880K |
| Retirement + cash | $450K + $20K → net worth ≈ **$1.35M** (house ≈ 65%) |
| Old monthly cost | 1,500 + 1,500 + 400 + 650 + 250 + 1,000 ≈ **$5,300** (≈ $63.6K/yr) |
| Upkeep rule of thumb | 1–2% of value = $12K–$24K/yr |
| Selling costs | 5% commission $60K + prep/closing/credit $18K = **$78K**; + moving $12K = **$90K** |
| Taxable gain | $1.2M − $78K − $450K = **$672K**; − $500K exclusion = **$172K** |
| Tax | 15% federal LTCG $25,800 + 3.8% NIIT on $112K (MAGI ≈ $190K wages + $172K − $250K) ≈ $4,256 + ~5% state $8,600 ≈ **$38,656** |
| Net cash | $1.2M − $78K − $12K − $319.5K − $38.7K ≈ **$751,900** |
| Cottage | $495K + ~$10K closing = $505K → ≈ **$247K** left |
| New monthly cost | tax $500 + insurance $150 + utilities $250 + upkeep $400 ≈ **$1,300** |
| Freed | ≈ **$4,000/month** = $48K/yr |
| Investing | $247K lump + $2,000/month at 6% for 7 yrs (55 → 62) ≈ **$579,500** ("close to $600K") |

| Improvements add to cost basis; keep records | IRS Publication 523 |
| Net investment income tax 3.8% above $250K MAGI (married filing jointly) | IRS (Form 8960) |

| ~49.9% of outstanding mortgages at ≤ 4% in Q1 2026 (peak 65.1% in Q1 2022) | Realtor.com analysis of FHFA National Mortgage Database data ([Wolf Street summary](https://wolfstreet.com/2026/03/27/update-on-the-lock-in-effect-in-the-housing-market-below-3-4-mortgages-fade-very-slowly/)) |
| 30-year fixed averaged 7.03% on Sept 24, 2026, first time above 7% since January 2025 | [Freddie Mac PMMS](https://www.freddiemac.com/pmms); [NPR](https://www.npr.org/2026/09/24/nx-s1-5977796/mortgage-rates-freddie-mac-homebuying) |
